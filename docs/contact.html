联系我

欢迎认识我，也让我认识你。

很高兴你来到这里，也欢迎你主动认识我。无论你的年龄、专业、职业或生活经历如何，都可以来打个招呼。不必和我有相似的背景，也不必先准备一个成熟的观点；我尤其期待那些能让我看见不同生活、不同问题和不同可能性的相遇。

我每周都会为社交留出时间，希望认识新朋友，也愿意花时间加深已有的关系。可以认真讨论，也可以轻松闲聊；可以一起学习、做点事情，也可以只是喝杯咖啡、散散步，体验一点新鲜事。

如果你想咨询我、希望得到一点帮助，或单纯想认识我，都很欢迎。你不需要先证明自己能带来什么。带着好奇、真诚和彼此尊重来就好。

研究 / 学术

欢迎与我进行学术交流，也欢迎探讨合作的可能，不限于我目前的专业与研究方向。信息科学的其他方向、理工科与工程问题，以及经济学和其他社会科学，都可以聊；我尤其希望交流微观经济学、博弈论、行为经济学与网络科学等领域。无论是讨论论文、一起学习、探索跨学科问题，还是提出一个尚在起步的合作想法，都很欢迎。

商业合作

如果你有值得一起尝试的产品、内容、活动或其他合作想法，欢迎聊聊。简单说说正在做什么、希望如何合作即可，想法还在早期也没关系。

个人想法 / 建议

欢迎分享一个问题、一段经历、不同意见，或推荐一本书、一篇文章、一门课。对网站和我的写作有建议或发现错误，也请直接告诉我。

播客 / 演讲 / 论坛 / 沙龙

欢迎邀请我参与对谈、播客、论坛、沙龙、读书会或小型聚会。可以作为分享者，也可以作为一起讨论和学习的参与者；告诉我主题、形式和大致时间就好。

生活 / 一起体验

咖啡、下午茶、吃饭、散步、运动、看展、逛博物馆、听演出、城市探索或结伴出行，都可以约。也欢迎带我尝试你熟悉而我还不了解的事；不在这份清单里的好主意，同样欢迎。

咨询 / 互相帮助

学习方法、大学生活、跨学科学习，或者一个你正在琢磨的选择，都可以聊。我会在自己的经验和能力范围内分享、一起想办法；不确定的地方也会坦诚说明。

认识彼此 / 重新联系

没有明确主题也可以联系。说说你最近在关注什么，或只是介绍一下自己。老朋友也随时欢迎回来聊聊近况；不同城市、不同时区，也可以先从文字或一次线上聊天开始。

从一句问候开始

不知道怎么开头？随意写两三句就可以：你希望我怎么称呼你、最近关心的一件事，以及想聊聊什么或一起做什么。加微信时可以备注“来自个人网站”，方便我认出你。

不用写得正式，也不必把这些逐项填完。若是约见面，顺手带上所在城市和方便的时间；如果我暂时没回复，过几天轻轻提醒一下也可以。期待从一句问候开始，慢慢认识彼此。
