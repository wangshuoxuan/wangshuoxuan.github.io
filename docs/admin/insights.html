访问统计与留言

从下面进入你的真实统计后台。访问数据保存在 Umami，留言保存在独立的私密留言后台。

查看全站访问统计访客数、访问次数、页面浏览量、访问时长、来源、设备和地区。 查看健康文章统计筛选 Health for a Better Life 的主要文章页面，查看访问与阅读情况。 查看阅读行为阅读时长档位、滚动深度、文章语言切换。 查看私密留言与回复使用站主账号登录，查看所有读者留言并逐一回复。

另有独立英文网址的访问记录：查看英文网址统计。主文章页面内部切换语言仍属于同一页面。

打开后怎么看？
  1. 如出现登录页面，使用此前创建 Umami 账号时的同一个 GitHub 登录；内容编辑器和留言后台的登录互相独立。
  2. 右上角选择时间范围，例如 Last 24 hours（最近24小时）、Last 7 days（最近7天）。确认没有遗留筛选条件。
  3. 在 Pages 中点击页面路径，查看该页；Overview 是概览，Events 是阅读行为，Realtime 是实时访问。

指标对照

后台名称含义
Visitors所选时段内估算的独立访客数，不等于实名人数，也不能判断某位具体朋友是否来过。
Visits访问会话次数；同一访客可以多次访问。
Views页面浏览次数，包括重复打开与刷新。
Visit duration估算的访问时长，不等于精确阅读时间。
active-reading文章在前台且近期有操作时累计的阅读时长里程碑：30、60、180、300秒。同一次阅读可能触发多档，事件数不是读者数。
reading-depth滚动到页面50%、90%的里程碑；不表示已读懂或逐字读完。
reading-language文章内 English、中文、英中按钮的切换记录。

没有看到数据时

先确认时间范围、网站选择和登录账号，再刷新后台。旧版空白统计面板已停用，这里无需再填写邮箱或等待邮件登录链接。

统计仍需网络连接。浏览器拦截、隐私设置或统计服务连接失败可能造成漏记；此前未记录的访问不能补回。来源与地区也不等于访客真实身份或所在地。

这里仅提供入口和使用说明，没有公开统计数据。实际统计需要你的 Umami 账号登录；未启用公开分享。
