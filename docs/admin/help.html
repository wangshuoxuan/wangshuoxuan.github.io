第一次连接，之后直接编辑。

你的可视化编辑器已经放在本网站内。日后可以直接打开 管理页面，选择栏目、填写表单、保存；不需要打开代码文件。

一次性设置编辑权限

  1. 用自己的 GitHub 账号打开细粒度访问令牌设置，选择 Generate new token。
  2. 名称可填写“个人网站编辑器”，在 Repository access 中选择 Only select repositories，并且只选 wangshuoxuan.github.io。
  3. Repository permissions 中仅将 Contents 设为 Read and write；Metadata 的只读权限会自动附带。当前网站不需要额外的工作流或管理权限。
  4. 自行生成并复制令牌，回到内容编辑器，选择 Sign In Using Access Token，粘贴令牌并登录。不要把令牌发到聊天、写进文章或上传到仓库。

这把“编辑钥匙”决定谁能保存到 GitHub。登录后编辑器会把它保存在当前浏览器中，供后续保存使用，因此请只在自己的可信设备上操作。令牌到期后需要重新连接，也可以随时在 GitHub 撤销。

日常使用

书籍、视频、文章收藏、论文、问题、应用与格言，使用中文表单和分类选择器。博客使用可视化正文编辑器。首页简介和公开联系方式也有单独表单。

草稿开关开启时不显示到网站；保存后等网站发布完成再刷新。公开仓库里的草稿文件仍可被查看。

当前支持范围

已配置上述栏目、博客、主页个人简介和联系方式。复杂布局、研究项目结构、CV 页面样式等仍需由维护者调整。

登录和实际保存仍需本人完成授权后核验。管理页面能打开不代表已获得写入权限，普通访客不会因此获得修改网站的能力。
